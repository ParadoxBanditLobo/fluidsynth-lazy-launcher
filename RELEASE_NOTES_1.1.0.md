# FluidSynth Lazy Launcher v1.1.0

A lightweight terminal frontend for playing MIDI files through SoundFonts with FluidSynth.

## Included

- Select MIDI and SoundFont files from configured folders
- Play and stop MIDI playback
- Render MIDI + SoundFont combinations to WAV
- Render to MP3 when FFmpeg is installed
- Random MIDI selection
- Persistent folder configuration
- Automatic output naming without overwriting existing renders

## Requirements

- Bash 4+
- FluidSynth
- FFmpeg (optional, MP3 export only)

No Python or pip packages are required.
